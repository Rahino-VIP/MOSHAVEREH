۱ ساخت جدول صف پیامک (`sms_outbox`) در Supabase

وارد پنل Supabase خود شوید، از منوی سمت چپ به SQL Editor بروید و کد زیر را Run کنید تا جدول صف ارسال ساخته شود: 

CREATE TABLE IF NOT EXISTS public.sms_outbox (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  customer_name text,
  phone text NOT NULL,
  message text NOT NULL,
  reason_badge text,
  is_sent boolean DEFAULT false,
  created_at timestamp with time zone DEFAULT now()
);

ALTER TABLE public.sms_outbox ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow all access to sms_outbox" ON public.sms_outbox
  FOR ALL USING (true) WITH CHECK (true);

۲ تنظیم شورتکات آیفون با نام `RahinoSMS` (برای ارسال خودکار ۵۰ پیامک)

بخش اول: دریافت لیست پیام‌های صف از سوپابیس

  1. در آیفون وارد اپ Shortcuts شوید و یک شورتکات به نام دقیق RahinoSMS بسازید.
  2. اکشن Get Contents of URL را اضافه کنید و آدرس زیر را قرار دهید:
https://YOUR_PROJECT.supabase.co/rest/v1/sms_outbox?is_sent=eq.false&select=id,phone,message

در قسمت Headers این اکشن، دو ردیف اضافه کنید:
• کلید apikey با مقدار کلید service_role سوپابیس
• کلید Authorization با مقدار Bearer YOUR_SERVICE_ROLE_KEY

بخش دوم: حلقه ارسال از سیم‌کارت و خروج از صف

  1. اکشن Repeat with Each را زیر مرحله قبل بگذارید.
  2. داخل حلقه، با سه اکشن Get Dictionary Value مقادیر phone، message و id را از Repeat Item بگیرید.
  3. اکشن Send Message را اضافه کنید، متغیر message و گیرنده phone را بدهید و تیک Show When Run را خاموش کنید.
  4. برای اینکه پیام دوباره ارسال نشود، یک Get Contents of URL دیگر با متد PATCH به آدرس /rest/v1/sms_outbox?id=eq.[id] و Request Body از نوع JSON با مقدار {"is_sent": true} بگذارید.
  5. اکشن Wait 4 seconds را در انتهای حلقه بگذارید تا اپراتور سیم‌کارت را مسدود نکند.
